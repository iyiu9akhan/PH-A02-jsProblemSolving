Problem-02: Elevator Weight Safety Checker
⚠️ Function Name Must be isElevatorSafe()

একটি অ্যাপার্টমেন্ট বিল্ডিং এর স্মার্ট এলিভেটরের সর্বোচ্চ নিরাপদ ওজন সীমা ৪০০ কেজি। দরজা বন্ধ হওয়ার আগে, এলিভেটরের সেন্সর ভেতরে দাঁড়ানো প্রতিটি মানুষের ওজন একটি Array আকারে রিড করে, এবং একটি ফাংশনকে ঠিক করতে হবে এটা চলা নিরাপদ কিনা।

📥 Input:
একটি Number array, যেখানে প্রতিটি সংখ্যা একজন মানুষের ওজন (কেজি) যেমনঃ [60, 75, 50]
🚀 Output:
একটি Boolean —

true যদি মোট ওজন ৪০০ কেজি বা তার কম হয় (চলা নিরাপদ)
false যদি ৪০০ কেজির বেশি হয় (ওভারলোড)
🚩 Challenge:
যদি

Input Array না হয়
তাহলে "Invalid" রিটার্ন করবে।

💡 Hints:
Array এর মধ্য দিয়ে loop চালিয়ে প্রতিটা weight যোগ করে মোট ওজন বের করো।
